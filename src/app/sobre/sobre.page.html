Sobre a PokéAPI

Este aplicativo consome dados diretamente da PokéAPI, uma API pública gratuita com uma vasta base de dados da franquia Pokémon.

Com ela, é possível acessar informações como nomes, habilidades, evoluções, tipos e sprites dos Pokémons. A PokéAPI é mantida pela comunidade e pode ser utilizada livremente para fins de estudo e desenvolvimento.

Acesse a documentação completa em:
https://pokeapi.co
